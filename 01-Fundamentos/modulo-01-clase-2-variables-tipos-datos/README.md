## 📖 Teoría

Una variable en *Java* es un espacio en memoria que guarda un valor.
En  *Java* se debe declarar:
- 📌 tipo de nombre = valor; 

- int edad = 25;
- double altura = 1.75;
- char letra = 'A';
- boolean activo = true;
- String nombre = "Carlos";

## 🔎 Tipos Primitivos
---
| **Tipo**     | **Guarda**         | 
|--------------|--------------------|
|:------------:|:------------------:|
| int          |   enteros          | 
| double       | decimales          |
| float        | decimales pequeños |
| char         | un solo carácter   |
| boolean      | true/false         |
| long         | entros grandes     |
---
## 📝 Tipo Especial: String
- *String NO es primitivo.*
Es una clase que representa texto.
`String mensaje = "Hola Java";`

## 🧠 Regla profesional de Java
Si declaramos:
`public class Usuario`
El archivo debe llamarse:
- Usuario.java
---
## 📌 ¿Por qué existe esta regla?
Porque Java organiza la compilación por nombre de archivo y clase principal.

Es parte de su diseño estructurado.
