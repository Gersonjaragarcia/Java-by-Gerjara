## 📖 Teoría
---
### 1️⃣ Operadores Aritméticos
Los operadores aritmeticos permiten realizar cálculos matemáticos básicos.
| **OPerador** | **Descripcion** | **Ejemplo**  |
|--------------|-----------------|--------------|
|     +        | Suma            |    5 + 3     |
|     -        | Resta           |    5 - 3     |
|     *        | Multiplicacion  |    5 * 2     |
|     /        | Division        |    20 / 5    |
|     %        | modulo          |    10 % 3    |
---
### ⚖ 2️⃣ Operadores Relacionales
Devuelven un valor booleano (true o false).
| **operador** | **Significado**   |
|--------------|-------------------|
|     ==       |    Igual          |
|     !=       |    Diferente      |
|     >        |   Mayor que       |
|     <        |   Menor que       |
|    >=        | Mayor o igual que |
|    <=        | Menor o  igual que|
---
### 🧠 3️⃣ Operadores Lógicos
Permiten combinar expresiones booleanas.
| **oprador**  | **Significado**   |
|--------------|-------------------|
|     &&       |    AND (y lógico) |
|     !        |    NOT (negación) |
---
